# Logo de Ojo Panamá

Un ojo con ondas que salen de un epicentro rojo, sobre azul marino (`#0b2a5b`, rojo `#da121a`).

| Archivo | Uso |
|---|---|
| `ojo-panama-mark.svg` | Marca sola en azul marino, para fondos claros |
| `ojo-panama-mark-white.svg` | Marca sola en blanco, para fondos oscuros |
| `ojo-panama-icon-1024.png` | Ícono de la app en las tiendas (App Store y Google Play). Cuadrado, sin transparencia: cada sistema redondea las esquinas |
| `android-foreground-1024.png` | Primer plano del ícono adaptable de Android (app nativa); el fondo es el color `#0b2a5b` |
| `icon-maskable.svg` | Fuente de `/icon-maskable-*.png` (la marca dentro de la zona segura, para el recorte de Android) |
| `badge.svg` | Fuente de `/badge-96.png`, la silueta de un solo color de las notificaciones de Android |

En la raíz de `public/`: `favicon.svg` (pestaña, con esquinas redondeadas), `icon.svg`, `icon-192.png`, `icon-512.png`
(manifiesto), `icon-maskable-192.png`, `icon-maskable-512.png`, `apple-touch-icon.png` (iPhone, 180 px) y `badge-96.png`.
